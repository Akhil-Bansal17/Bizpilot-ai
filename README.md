# BizPilot AI — Business Operations Copilot for Restaurants & Cafés

**BizPilot AI** is a production-ready, AI-powered Business Operations Copilot designed specifically for restaurants and cafés. It integrates sales tracking, menu intelligence, inventory management, recipe-driven consumption, expense tracking, demand forecasting, stockout prediction, anomaly detection, and actionable business recommendations.

> **Product Promise:** *"Know what happened. Understand why. Predict what's next. Know what to do."*

---

## 🏛️ Core Architectural Principle

BizPilot AI enforces a strict deterministic-to-explanatory flow:

```
Database → Validated data → Deterministic calculations → Analytics
→ ML predictions → Recommendation engine → Evidence package → LLM → Human-readable explanation
```

The LLM is **never** the source of truth for business facts (sales totals, inventory levels, cost calculations, or margins). It acts exclusively as an interpreter and reasoning agent over structured evidence generated by deterministic domain logic, analytics algorithms, and ML engines.

## 🚀 Quick Start

### 1. Environment Setup

Copy `.env.example` files to `.env` in both `backend` and `frontend`:

```bash
# Backend
cp backend/.env.example backend/.env

# Frontend
cp frontend/.env.example frontend/.env
```

### 2. Run with Docker Compose (Recommended)

To start the database, backend, and frontend together:

```bash
docker-compose up --build
```

- **Frontend App:** [http://localhost:5173](http://localhost:5173)
- **Backend API:** [http://localhost:8000](http://localhost:8000)
- **API Documentation (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)
- **Database:** PostgreSQL on `localhost:5432`

## 🛠️ Local Development (Without Docker)

### Backend Setup

1. Create a Python virtual environment:
   ```bash
   cd backend
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt -r requirements-dev.txt
   ```

3. Run migrations:
   ```bash
   alembic upgrade head
   ```

4. Start the FastAPI dev server:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

5. Run backend tests:
   ```bash
   pytest
   ```

### Frontend Setup

1. Install Node.js dependencies:
   ```bash
   cd frontend
   npm install
   ```

2. Start the Vite dev server:
   ```bash
   npm run dev
   ```

3. Run frontend tests:
   ```bash
   npm test
   ```

4. Check types & linting:
   ```bash
   npm run typecheck
   npm run lint
   ```
